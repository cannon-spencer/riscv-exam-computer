\section{Alpha objective}
%=============================================================================

The alpha goal is \textbf{Safe Exam Browser running on the Debian board}: a student-facing locked browser on the RISC-V hardware.

Repository: \url{https://github.com/cannon-spencer/riscv-exam-computer}

CI in \texttt{reptilian-riscv} builds the Debian image. Scripts here flash that image and install on-device software (\texttt{flash-os.sh}, \texttt{install-software.sh}). A board can boot Debian, join the network, and run \texttt{seb-agent}, which POSTs a heartbeat to a listener.
