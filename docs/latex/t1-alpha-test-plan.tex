\section{Scope}
%=============================================================================

This plan is for the alpha build. The pass criterion is \textbf{Safe Exam Browser running on the CI-built Debian image} on the Orange Pi RV.

\paragraph{In scope.}
Image flash and boot; network; build and launch of \texttt{seb-linux} on that Debian; basic lockdown once SEB is up.

\paragraph{Out of scope.}
Instructor control plane (start/stop jobs, fleet UI), Canvas exam completion, and kernel hardening.

\paragraph{Lab baseline.}
Default login \texttt{orangepi}/\texttt{orangepi}. UART 115200. \todo

\subsection{Board and image}
\label{sec:eb-boot}

CI in \texttt{reptilian-riscv} publishes a Debian \texttt{os.img.xz}. \texttt{flash-os.sh} writes it to SD. After power, the board reaches a Linux login (UART and SSH). Wi-Fi or Ethernet yields IPv4 and outbound connectivity.

\subsection{SEB on Debian}
\label{sec:eb-seb}

\begin{itemize}\setlength{\itemsep}{0.12em}
  \item \texttt{seb-linux} builds on riscv64 using the WebKitGTK fallback (no Qt6 WebEngine package).
  \item SEB launches on the Debian graphical session.
  \item While running: fullscreen; ordinary desktop exit paths do not dismiss the kiosk; policy-blacklisted processes are refused or terminated.
\end{itemize}

\subsection{\texttt{seb-agent} heartbeat}
\label{sec:eb-hb}

\texttt{install-software.sh} copies \texttt{seb-agent} to the board. The agent POSTs a JSON heartbeat to a control URL every 5\,s.
