# Archive
 
This folder contains the handed-off OS (`reptilian-riscv`) as a git
submodule, pinned to the exact commit we were given.
 
It's kept here, linked rather than copied, so the original handed-off
version stays intact and untouched. Any work or modifications should
happen outside this folder, not inside the submodule itself. That way
we always have the original to reference or fall back to.
